# 🐂 CapatazTech

Sistema de gerenciamento de fazenda e rebanho bovino.

## 🛠️ Tecnologias
* Java 25
* Spring Boot
* Spring Data JPA
* Thymeleaf
* H2 Database
* Bootstrap
* Swagger

## ⚙️ Funcionalidades
* Cadastro e listagem de Animais e Vacinas (com relacionamentos).
* Registro de aplicação de vacinas.
* **Venda de Animais:** O sistema calcula automaticamente a idade e o valor pelo peso, e bloqueia a venda dupla.
* API REST documentada com Swagger.
* Dashboard com dados em tempo real.

## 🚀 Como rodar
1. Clone o repositório.
2. Abra na IDE (IntelliJ).
3. Rode a classe `CapataztechApplication`.
4. Acesse: `http://localhost:8080`

**Acesso ao Swagger:** `http://localhost:8080/swagger-ui.html`
